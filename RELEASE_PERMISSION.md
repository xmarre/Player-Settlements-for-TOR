# Release permission record

Status: blocked

GitHub release publishing must remain blocked until written authorization covers:

- modification of the upstream Player Settlement source;
- redistribution of the resulting source and compiled binaries on GitHub; and
- any included third-party or The Old Realms assets.

When authorization is obtained, record the author or rights holder, the date, the
scope, and a durable reference to the written permission here. Then change `Status`
to `approved` and set the repository Actions variable `RELEASE_APPROVED` to `true`.
