Player Settlement 7.6.9 visual startup fix
================================================

Target
------
- Mount & Blade II: Bannerlord 1.3.15
- The Old Realms: War in the Mountains 1.16
- Upgrade from Player Settlement 7.6.8.2

Confirmed diagnosis
-------------------
The 7.6.8.2 diagnostic build identified the repeated startup errors as two
custom settlement visuals entering PlayerSettlement's SettlementVisual.OnStartup
prefix with incomplete visual state.

Each affected settlement produced two messages:
1. PlayerSettlement.Patches.PartyVisualPatch.OnStartup threw a NullReferenceException.
2. The prefix caught that exception and returned control to Bannerlord's original
   SettlementVisual.OnStartup, which then threw a second NullReferenceException.

The template loader, all post-menu compatibility initializers, and all hotkey
manager creation calls completed successfully. They were not the source.

Fixes
-----
- Rebuilt PlayerSettlement.dll as version 7.6.9.0.
- Reworked custom SettlementVisual.OnStartup with explicit null-safe prerequisites.
- Prevented the native SettlementVisual.OnStartup fallback after a custom visual
  has already entered PlayerSettlement's custom startup path.
- Added null-safe strategic entity, map scene, map banner parent, siege frame,
  town component, and map visual dictionary handling.
- Added bounds-safe application of saved rotations and deep visual edits.
- Integrated same-culture ToR visual copying directly into PlayerSettlement.dll.
- Removed the external PlayerSettlementCultureVisuals helper assembly and loader.
- Removed the temporary 7.6.8.2 startup diagnostic submodule.
- Preserved exact-culture settlement previews and removed cross-culture visual retry.
- Preserved the village raid visual-lifetime fix.
- Preserved the custom town/castle native ownership transition used by siege AI.
- Preserved non-player ownership on conquered or transferred custom settlements.
- Added no recurring campaign-map scans or per-tick campaign work.

Installation
------------
Delete both existing folders before installing:
  Modules\PlayerSettlement
  Modules\PlayerSettlement_TOR

Install both folders from this archive and fully restart the game.

Runtime verification
--------------------
1. Load the same save that produced four red NullReferenceException messages.
2. Confirm the messages no longer appear when campaign-map settlement visuals start.
3. Confirm existing and newly created custom settlements retain correct map models.
4. Start, interrupt, complete, and save/reload during a raid on a custom village.
5. Confirm hostile AI can form and maintain a siege against eligible custom towns/castles.
6. Confirm a custom fortification owned by another clan remains with that clan after reload.
