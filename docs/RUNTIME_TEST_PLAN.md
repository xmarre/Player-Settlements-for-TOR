# Runtime acceptance tests

1. Load an existing save with a player-built town or castle.
2. Confirm the log contains `Strategic neighbour integration` with at least one neighbour.
3. Verify the settlement remains owned by its current clan, including conquered/transferred custom settlements.
4. Declare war and run campaign time for at least several AI decision cycles.
5. Confirm hostile lords or armies can select, approach, begin, maintain, abandon, and later reselect the custom fortification under normal native strategy rules.
6. Build a new town and castle and repeat the target-selection check without restarting.
7. Start, interrupt, complete, and save/reload a raid on a generated village.
8. Verify campaign-map performance has no recurring scan or new per-tick work.
